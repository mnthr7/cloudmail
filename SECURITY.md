# Security policy

CloudMail handles people's mail, so security reports are welcome and taken seriously.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through
[GitHub's private vulnerability reporting](https://docs.github.com/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
(**Security → Report a vulnerability** on this repository).

Include what you found, how to reproduce it, and what an attacker could do with it.
You should hear back within a week.

## Scope

In scope: the CloudMail code in this repository, including the Worker, the web app,
the inbound mail handling, and the provided GitHub workflows.

Out of scope: your own Cloudflare or Resend account setup, and issues that need an
already-compromised admin account.

## Supported versions

Only the latest release on the default branch gets security fixes.
